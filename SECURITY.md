# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in Kraiiv, please
report it privately so it can be fixed before public disclosure.

**Do not open a public GitHub issue for security problems.**

Contact: open a private report via
https://github.com/xi-kki/kraiiv-mvp-flutter/security/advisories/new
(GitHub private vulnerability reporting), or email the repository owner
directly.

Please include:

- The affected file and line(s) if known
- A description of the vulnerability and its impact
- A minimal reproduction (request, payload, or steps)
- Any suggested fix

## What to expect

- Acknowledgment of your report within 5 business days
- A fix timeline agreed with you based on severity
- Credit in the release notes if you would like it (unless you prefer anonymity)

## Scope

This policy covers the code in this repository, including the Flutter app
(`lib/`) and the model API (`model-api/`). The deployed marketing landing
page is a separate project and is out of scope.
